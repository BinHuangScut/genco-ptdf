# 经典 AC 雅可比实现与使用

核心在 `genco_ptdf/classical.py`。程序先解出运行点的 AC 潮流，再在这个
**收敛点**重新建立雅可比。每个运行点只对雅可比分解一次，把多笔交易作为
多个右端项一起求解；计算 PTDF 不需要为每条线路、每笔交易重跑潮流。

设非参考节点顺序为 PV 后接 PQ，状态是这些节点的相角与 PQ 电压幅值：

```text
x = [θ(PV,PQ), Vm(PQ)]
J = [[∂P/∂θ, ∂P/∂Vm],
     [∂Q/∂θ, ∂Q/∂Vm]]
dx/dt = solve(J, [D(PV,PQ)/baseMVA; 0])
AC-PTDF = baseMVA × [∂Pfrom_pu/∂θ, ∂Pfrom_pu/∂Vm] × dx/dt
```

IEEE 14 的 J 是22×22，完整 PTDF 是20×13；IEEE 118 的 J 是181×181，
完整 PTDF 是186×117。相角导数使用弧度，输入交易以 MW 为单位，输出是
线路规定方向送端的 MW/MW。两处 baseMVA 的位置保证了单位一致。

`D` 每列是一个净注入变化：交易 a→b 在 a 行为+1、b 行为−1。矩阵的行
遵循 `grid.ids`，不能把母线编号直接当数组索引。`transfers=None` 返回
完整基矩阵，每个非参考节点注入+1 MW，由参考节点平衡。任意平衡交易都
可以由这个基矩阵线性组合得到。

求导时固定 PQ/PV 类型、PV/参考电压设定、参考相角、Qd、分接头和相移。
非参考节点计划出力在交易方向以外保持固定。参考机组实际出力由潮流决定，
承担增量网损，因此实际参考节点净注入变化不必恰好等于名义交易中的−1。

最终实现直接调用 `pandapower.pypower.newtonpf`，使用 DataKit 导纳矩阵，
并在收敛点调用 pandapower 的解析导数核重建雅可比。独立 `pandapower.runpp`
校验相同的电压解。原标签由等价稀疏 Newton 迭代生成，全部基准状态、完整
雅可比标签和扰动状态残差已完成核验。校验还覆盖中心
差分、参考节点交易端点、非零相移、多机组同节点映射、线路方向和单位。

## 本机运行

在 WSL 中进入 `/mnt/e/projects/genco`，环境位于
`$HOME/.venvs/genco-ptdf`。主要命令见根目录 README。训练完成后，
`evaluate` 会校验所有交付模型的导数，再计算完整测试指标；`report` 会
根据实际指标生成四组图和英文参赛说明。

数据清单是 `data/<grid>/manifest.json`，训练记录在
`checkpoints/finetuned/<grid>/<pf或response>/seed*/`。指标表同时区分
常规负荷和较高负荷。限额越界不改变控制模式，而是单独记录，因此这些
灵敏度描述的是固定控制条件下的数学响应。

普通 PF 微调与响应微调使用相同的基准点和扰动状态标签；额外的响应损失
拟合±0.1/±1 MW中心差分。最终测试使用自动微分，并增加未参与训练的+5 MW
交易增量测试。结果中不预设响应训练一定更好，也不预设神经方法一定更快。
